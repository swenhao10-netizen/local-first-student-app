# 本地优先学生 App

面向学生与年轻人的 Android 本地优先 App，首版规划三个模块：背单词 / 学习卡片、习惯 / 专注、轻量记账。

## 当前原则

- Android 首发，中文优先，适配碎片时间和离线环境。
- 首版默认无账号；记录保存在本机，支持导出、备份和恢复。
- 阶段 0 不做广告、订阅、内购和默认后台遥测。
- 开发前先检索 GitHub 现有项目和成熟组件，检查许可证、维护状态、Android 适配、数据模型和隐私风险；能复用就集成或改造，不重复造轮子。
- 健身记录暂不纳入首版；未来加入时必须作为独立验证模块，不能直接复制 openGym。

## 当前阶段

项目仍在产品验证与技术方案阶段。Hark 已完成候选方向和通用流程探索；TRAE 应先提交共享本地数据、导入、导出、备份和回滚的技术方案，再实现具体模块。
