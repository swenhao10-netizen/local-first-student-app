知行 v0.4.0：液态玻璃界面 + 五项体验修改。

**新外观**
- 液态玻璃主题（默认开，「我的 → 外观」可关）：底栏选中块按住能左右拖，像水珠一样滑过去；「+」、搜索、发布、背词按钮都是会弹的液态玻璃。模糊需 Android 12+，折射需 Android 13+，更低版本自动半透明。
- 自定义背景：「我的 → 外观 → 自定义背景」换成自己的图片。
- 新图标：招手小猫；新启动动画（冷启动播一次，点一下跳过）。

**体验修改**
- 记录里的图片点开全屏看大图。
- 带图记账改为：文字 → 图片 → 图下分类和金额，去掉外框。
- 总览去掉当天列表，修复 -¥0.00。
- 「不认识」的词收进单独的「不记得的单词」页。
- 背词先隐藏释义，点「认识 / 不认识」后再显示。
- 去掉示例卡片，自己加的卡片可以删除。
- 修复深色模式下文字发黑。

覆盖安装即可，数据不会丢。要求 Android 8.0 及以上。
