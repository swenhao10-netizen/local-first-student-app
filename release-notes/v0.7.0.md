## 知行 v0.7.0

**自动记账**
- 微信、支付宝、云闪付付款后，知行读到付款通知，弹「记一笔 ¥xx？」，点「入账」就记进账本
- 按商家自动分类（餐饮、交通、购物、娱乐、学习、其他），点「换分类」轮换
- 可关掉「入账前先问我」，改成直接入账，通知里能撤销
- ColorOS 16 / 安卓 16 上会请求进流体云胶囊；更早的系统是悬浮通知
- 退款、收款、红包、转账不记；同金额 3 分钟内只记一次
- 在「我的 → 设置 → 自动记账」里开启，需要在系统里给知行「通知使用权」
- 只在本机识别，不联网

**说明**
- 未在真机上测试；微信、支付宝通知文案会变，认不出时不会记账
